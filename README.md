# MAX Watcher (Android)

Слежение за уведомлениями в MAX (web.max.ru) через встроенный WebView.

## Возможности
- Периодическая проверка непрочитанных чатов через JS-инъекции
- Автоматическое открытие чатов с новыми сообщениями
- Скачивание файлов и картинок
- Скриншоты чатов с текстом
- Локальные уведомления Android (тап открывает приложение)
- Автозапуск при загрузке устройства
- Ручные ответы в MAX — через тот же WebView

## Установка
1. Открыть папку проекта в Android Studio.
2. Дождаться Gradle sync (5–10 минут).
3. Build → Build Bundle(s)/APK(s) → Build APK(s).
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.
5. Установить на телефон, разрешить «Неизвестные источники».

## Первый запуск
1. Открыть приложение → загрузится MAX.
2. Войти в свой аккаунт в WebView.
3. Дождаться списка чатов.
4. Нажать «▶ Запустить».
5. Разрешить уведомления (Android 13+).
6. Нажать «Батарея» → разрешить работу в фоне.

## Как отвечать в MAX
Открыть приложение → в WebView открыть чат → напечатать → Enter.
Сессия залогинена, всё работает.

## Где лежат файлы
- `Android/data/com.example.maxwatcher/files/downloads/` — скачанные файлы и картинки
- `Android/data/com.example.maxwatcher/files/screenshots/` — скриншоты чатов

Доступ через файловый менеджер или кнопку «Файлы» в приложении.
